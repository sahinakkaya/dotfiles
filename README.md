# My dotfiles

My dotfiles for Linux and macOS, managed with [chezmoi](https://www.chezmoi.io/).

## Installation

Bootstrap new machines with:

```sh
sh -c "$(curl -fsSL sahinakkaya.dev/install)"
```

It will configure the shell, terminal, editor, and desktop, along with Git and SSH,
using my personal defaults.

## Updates

```sh
chezmoi update
```
